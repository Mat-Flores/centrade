# Décisions d'architecture (ADR)

Une ADR est requise pour toute dépendance hors SPEC §5 et pour tout écart au SPEC (§0.2, §0.14). Fichiers `NNNN-titre-court.md`, numérotation continue. Une ADR acceptée ne se supprime pas : une nouvelle ADR la remplace.

Format : titre `ADR-NNNN : …`, puis les sections Statut (Proposée, Acceptée, Remplacée par ADR-NNNN), Date, Contexte, Décision, Alternatives écartées, Conséquences.
